what gets checked

every javascript and css file justtype.io serves, plus index.html (the loader that decides what runs), is downloaded by your browser here, hashed, and compared against the hashes github actions produced by building the public repository. the release signature is checked against the pinned release key, which lives on the developer's machine and never on the server. in the app itself the loader repeats the signature check on every page load and pins every file with subresource integrity, so a server that cannot sign a release cannot get your browser to run modified code.

beta builds (beta.justtype.io) are not published here and are not signed; they pin files against the server manifest only.

build it yourself

zero trust required: clone, build, compare.

git clone https://github.com/alfaoz/justtype.git
cd justtype
npm ci
VITE_TURNSTILE_SITE_KEY="0x4AAAAAACSJvMqEG5Z-iXyo" npm run build
cat dist/build-manifest.json

the turnstile site key is public and baked into the bundle; without it the hashes will not match.
